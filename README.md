# ホロライブ グッズカレンダー

ホロライブ関連グッズの販売・受注期間を、日付×商品のカレンダーで一覧できるページです。
ファンが個人で作成している**非公式**のページで、カバー株式会社・ホロライブプロダクションとは関係ありません。

- 公開ページ：https://ohagi-rikuou.github.io/holo-goods-calendar/
- 情報の出典：hololive production OFFICIAL SHOP、各社の公式発表・公式サイトなど（各商品の出典URLはページの詳細欄に記載）。購入前に必ず元の販売ページで最新情報を確認してください。

抜けている商品や誤りは、Discordサーバーのスレッドで商品ページのURLを教えてください。

## 更新のしくみ

| 対象 | 更新方法 |
|---|---|
| 公式ショップの商品 | 毎日 0時ごろ（日本時間）に自動更新（GitHub Actions） |
| 企業・店舗・プライズ・くじ など | 手動で `data/manual.json` を更新してアップロード |

自動更新でやること：新しく掲載された商品の追加（NEWタグ）、販売期間・発送予定の変更の反映（更新タグ）、SOLD OUT の反映、ショップから消えた商品と終了から7日たった商品の削除。
取得に失敗した日は、データを変えずに前回の内容のまま公開を続けます。

あわせて毎日、AIの読み取りを許可しているニュース・公式サイト（PR TIMES、公式ショップのお知らせ、インサイド、アニメ！アニメ！、ホロライビュアーズ、コラボカフェ）の新着から、まだ載っていない商品の候補を `data/candidates.json` に書き出します（カレンダーには自動では載りません）。手動更新のときに候補を確認し、販売元の情報で確かめてから `data/manual.json` に登録します。確認済みの候補は `data/candidates_reviewed.json` に記録します。

発表はされたが詳細がまだの商品は `data/watchlist.json`（注目キーワード）で見張り、関連する記事が出たら【注目】として候補の先頭に出します。注目キーワードは「見つかるまで」（情報が出て登録したら、外すか残すかを確認）と「ずっと監視」の2種類です。

## 掲載範囲（詳細）

ページ下部には短い説明だけを表示しています。詳しい基準は次のとおりです。

公式ショップ：販売期間・受注期間のある商品。期限のない通常販売（在庫販売・予約販売、hololive friends や Regular Outfit などの定番商品を含む）は、新商品として出たとき（7日間）と、売り切れ（30日間）・再入荷予定・販売再開（7日間）のときだけ掲載。企業・店舗：PR TIMESの発表（2026年8月〜10月）のうち、販売中・販売予定のもの。ホロカ：公式サイトの商品情報のうち発売前のもの。プライズ：バンダイスピリッツ・フリューの公式プライズサイトとタイトー店舗の入荷予定（9月以降の登場分）。くじ・フィギュア：エニマイ公式、一番くじは報道、あみあみの予約受付中商品。コラボ：ローソン・ジョイポリス・カプコンの公式情報。海外：ホロライブ公式サイト（英語版）ニュースと各社の発表から、海外で開催・販売されるもの（「海外」タグ付き）。

## ファイル

- `index.html` … ページ本体
- `data.js` … ページが読むデータ（自動で作られるので直接編集しない）
- `data/shop.json` … 公式ショップの商品（自動更新）
- `data/manual.json` … 手動で追加した商品
- `data/members.json` … メンバー・期生・推しマーク
- `data/meta.json` … 種別名・掲載範囲の説明
- `scripts/update_shop.py` … 公式ショップの取り込み
- `scripts/build.py` … `data/*.json` から `data.js` を作る
- `scripts/find_candidates.py` … 漏れ候補リストの作成
- `.github/workflows/update.yml` … 毎日の自動実行と公開の設定
